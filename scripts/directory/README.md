# دليل «أدوات عالمية»

بيشتغل على GitHub Actions (عشان محتاج يزور مواقع الأدوات):

1. `seeds.mjs`: بيجمع أسماء وروابط الأدوات من قوائم مفتوحة على GitHub. بياخد الاسم والرابط بس، والأداة الموجودة في أكتر من قايمة بتيجي الأول.
2. `build.mjs`: لكل أداة بيزور موقعها الرسمي وصفحة الأسعار، وبياخد الشعار من الموقع نفسه، وبيكتب صفحة بالعربي من كلام الموقع بس. الأداة اللي موقعها واقف أو مش أداة ذكاء اصطناعي بتتسجل في `failed.json` ومش بتتكرر.

## قبل أول تشغيل
في GitHub: Settings → Secrets and variables → Actions → New repository secret
- `GROQ_API_KEY` (الأساسي)
- `OPENROUTER_API_KEY` (احتياطي لما Groq يبقى زحمة)

## التشغيل
Actions → build-directory → Run workflow → اكتب العدد (مثلاً 300). التشغيلة بتكمّل من مكان ما وقفت.
